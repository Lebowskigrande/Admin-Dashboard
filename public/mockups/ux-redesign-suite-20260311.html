UX analysis + mockups

Three design directions: a real operations cockpit, a focused task workbench, and a dense records studio.

The current app has strong operational depth but the visual system is still page-local. These mockups show how to unify hierarchy, increase scan speed, and make dense data feel lighter and more interactive.
