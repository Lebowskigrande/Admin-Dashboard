SE UX REVIEW + REDESIGN DIRECTION

Make the dashboard feel like an operations cockpit, not a stack of admin forms.

The app already has solid module coverage and useful detail panels. The biggest opportunity is to sharpen hierarchy, expose urgency faster, and move dense pages toward a real workbench model.

Current strengthClear module coverage
Current weaknessToo many equal-weight cards
Design goalFaster triage, denser execution
13 top-level destinations today
Best current pattern: queue + detail
Primary gap: urgency is readable, not instantly visible

What should stay

Strong domain separation, reusable card patterns, and the existing detail-pane model are worth preserving.

Clear page segmentationSunday, Finance, People, Buildings, Calendar, and Vestry already map to recognizable work modes.
Good workflow foundationTask and people pages already hint at a workbench interaction shape.

What is slowing users down

The UI is clean but too even. Critical, passive, and secondary data often share the same visual weight.

Navigation is flat and longEverything competes in a single rail with minimal grouping.
Data density is moderateToo much height is spent on framing before users reach the real work.

System shifts

This should be more than a reskin. The redesign should shorten the gap from awareness to action.

Grouped navigation bandsCommand, Planning, Records, Systems.
Workbench pagesQueue left, execution center, context rail right.
Compact record rhythmSticky context, denser rows, and fewer decorative borders.
